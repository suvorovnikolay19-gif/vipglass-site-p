# VIP Glass — комплект для передачи дизайна

Дата: 16 октября 2026 года. Это полный снимок актуального проекта: исходный код, готовая статическая сборка, рабочие изображения и миниатюры, шрифты, видео, данные каталогов, исследования и проверки.

## С чего начать

1. Прочитайте `vipglass-site/docs/CLAUDE-DESIGN-BRIEF.md` — задание на визуальную переработку и требования, которые нужно сохранить.
2. Прочитайте `vipglass-site/docs/SITE-HANDOFF.md` — устройство сайта, назначение файлов, добавление материалов и порядок сборки.
3. Работайте в папке `vipglass-site`. Краткая сводка проекта и проверки есть в `README.md`.
4. Для поиска нужной страницы используйте `handoff/ALL-PAGES.csv`; для поиска её изображения — `handoff/IMAGE-USAGE.csv`. `handoff/CATALOG-TREE.json` содержит дерево конструкций с вложенными подразделами.

Важная особенность: `dist/` содержит **редактируемые JavaScript-модули, CSS и медиа**, а также сгенерированные HTML. Не удаляйте её как обычную временную папку сборки. Общая HTML-оболочка редактируется в `src/shell.html`, страницы пересоздаются командой `node build-pages.mjs`.

## Сообщение для Claude

> Перед нами действующий многостраничный прототип VIP Glass. Нужно переработать визуальный дизайн и изображения, сохранив глубину каталогов, адреса страниц и работающие сценарии выбора. Сначала прочитай `docs/CLAUDE-DESIGN-BRIEF.md` и `docs/SITE-HANDOFF.md`, затем изучи существующие исходники. Результат нужен в виде полного обновлённого проекта, пригодного для обратной интеграции, с `DESIGN-CHANGELOG.md`. Стекло в бесцветных конструкциях — только осветлённое Crystal Vision без зелени. Все четыре входа «Цельностеклянные / Каркасные / Лофт / SMART» должны сразу считываться в перегородках. Каждой странице требуется своё точное изображение; общий кадр с разными названиями не подходит. Фурнитура — только изображения подтверждённых изделий из согласованных каталогов, без артикулов; в зеркалах подбора фурнитуры нет. Не заменяй глубокий каталог макетом одной страницы.

## Что находится дополнительно

- `handoff/RELEASE.json` — точная опубликованная ревизия и дата комплекта.
- `handoff/ALL-PAGES.csv` — все адреса с разделением основных страниц и совместимых старых путей. Точные количества указаны в `handoff/RELEASE.json`.
- `handoff/IMAGE-USAGE.csv` — назначение основных изображений страницам конструкций, материалов, производства и фурнитуры; рабочие файлы находятся в `dist/assets/`.
- `handoff/CATALOG-TREE.json` — вложенная структура каталога конструкций.
- `references/map-motion-reference.mp4` — присланный видеореференс появления объекта из карты.
- `references/material-filter-reference.png` — присланный скриншот, по которому исправлено конфликтное сочетание фильтров.
- `docs/` — исследования присланных конкурентов, модели контента, история изменений, источники и промпты изображений, ограничения и результаты проверок.

Изображения в архиве сохранены в рабочих размерах сайта вместе с миниатюрами. **Полная замена изображений всех страниц на уникальные точные ещё не завершена:** на части страниц остаются прежние общие примеры. Это зафиксированная незавершённая работа, а не допустимое исключение. Очередь и критерии — `docs/exact-image-plan.json`; отдельные проверенные изображения подключаются через `dist/exact-catalog-media.mjs`. Реальные работы и отзывы не подменены вымышленным портфолио. Локальные пользовательские черновики браузера не являются частью исходного проекта.

## Как вернуть результат

Передайте обратно полный обновлённый проект и `DESIGN-CHANGELOG.md`, новые изображения в локальных файлах, а также несколько кадров широкого и мобильного вида. Укажите, какие проверки выполнены и что осталось непроверенным. На основе этого комплекта можно продолжить работу и обновить существующий сайт по прежней ссылке.
