# VIP Glass: раскрывающаяся объёмная карта

## Результат

`dist/location-scene.mjs` строит самостоятельную трёхмерную миниатюру. SVG — способ
вывода проекции, а не исходное плоское изображение: геометрия хранит координаты
`[x, elevation, z]`, камера использует перспективное преобразование, грани имеют
освещение и сортируются по глубине, невидимые стороны непрозрачных тел отсекаются.
Вращение камеры открывает другие стороны павильона.

Павильон является **авторской концепцией**, не реконструкцией настоящего здания.
Окружение — стилизованная схема, а не геодезически точная карта. Адрес и географическая
точка выводятся интерфейсом отдельно. Внутри миниатюры нет вымышленных названий улиц.

## API

```js
renderLocationScene({
  progress: 1, // 0..1
  yaw: -25, // degrees; orbit
  pitch: 42, // degrees; elevation, clamped 23..76
  zoom: 1, // clamped .7..1.45
  width: 1000,
  height: 720,
  time: 0 // seconds; deterministic miniature traffic
});
```

Возвращает полный SVG с `viewBox`, подписью доступности и без сетевых запросов.
`createLocationSceneGeometry(progress, time)` возвращает исходную геометрию и
счётчики. `projectLocationPoint(point, camera)` возвращает экранную проекцию и
глубину. `locationSceneInfo` содержит описание стадий и параметры по умолчанию.

## Режиссура

- `0..0.25`: объёмная метка опускается на поверхность.
- `0.20..0.68`: восемь бумажных лепестков карты изгибаются и раскрывают отверстие.
- `0.41..0.94`: стеклянный павильон поднимается; скрытая под картой геометрия
  обрезается на уровне земли.
- `0.88..1`: слегка открывается одна из двух входных дверей.

Рекомендуемое время — 6.2 секунды. Камера может одновременно перейти от
`yaw=-34,pitch=64` к `yaw=-25,pitch=42`. После завершения доступно ручное вращение.
Пять маленьких автомобилей перемещаются по схеме через параметр `time`.

Внешний интерфейс отвечает за запуск, повтор, остановку, drag/keyboard controls,
`prefers-reduced-motion`, остановку вне экрана и очистку RAF при смене страницы.
Рекомендуемый предел обновлений SVG — 30 кадров в секунду. При reduced motion
показывать конечное состояние; ручное изменение камеры остаётся доступным.

## Содержание

Павильон включает нейтральное прозрачное остекление, прозрачную кровлю, тонкий
тёмный каркас с тёплыми металлическими деталями, стеклянную двойную дверь,
зеркальный экспонат и три образца стекла, стеклянный стол, ступени и вывеску
`VIP GLASS`. Зелёного оттенка прозрачного стекла нет. Наличие такой экспозиции
в реальном офисе миниатюра не подтверждает.

## Проверка

Проверены 101 состояние раскрытия: конечные координаты, допустимые полигоны,
не более 655 граней. Разные ракурсы дают разные проекции. В SVG отсутствуют
внешние изображения, скрипты и запросы. Около 78 КБ на конечное состояние,
примерно 2.7 мс генерации кадра в доступном Node runtime (не браузерный бенчмарк).

Промежуточное раскрытие, финальный вид и противоположный ракурс экспортированы
через установленный `sharp` и просмотрены. Браузерное воспроизведение, мобильная
производительность и пользовательские управляющие элементы проверяет интегратор;
в текущей среде браузерная проверка недоступна.
